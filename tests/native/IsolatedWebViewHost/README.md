# Isolated WebView2 renderer

This one-shot test program renders local fixture pages with the installed WebView2 runtime and an exclusive temporary profile. Windows Forms only provides the HWND and STA message pump; a real `CoreWebView2Controller` owns the renderer. The SDK, resource allowlist, production fixture markup, computed-layout assertions and screenshot checks are unchanged. The test executable is self-contained and does not require the developer's runtime path.

On an explicit close request, it closes the controller, waits for `BrowserProcessExited(Normal)` for the exact owned browser PID, and flushes the `closed` record. It then closes its window and returns from `Application.Run` and `Main` normally. It does not call `Environment.Exit` or kill its own process. An interrupted render exits with code 1 even if the browser closed normally. Startup, navigation, close and SDK events include bounded timing and thread diagnostics.

The Node runner independently verifies the process exit, stream closure, and release of the observed process identities under the original 30-second deadline. EOF without a final response is a failure, never an implicit acknowledgment. This verifies the isolated renderer and its Core cleanup. The shipping application's WinUI window, retained chat Core, physical input and dispatcher shutdown require a separate native acceptance run. This test host is never shipped in the installer.
