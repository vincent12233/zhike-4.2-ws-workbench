# 知客 4.4.16 WS 账号状态同步

## 修复

- WS BrowserView 的运行态会通过账号级 PATCH 写入 `ws_accounts.status`，账号列表和数据库状态保持一致。
- 连续状态变化使用按账号队列合并，避免重连、探测和页面加载事件互相覆盖。
- 应用重启时将上一进程遗留的“已连接 / 登录中 / 正在重连”恢复为“未连接”，待新 WS 页面探测成功后再写回真实状态。
- 增加账号状态 API 与 Electron 主进程状态持久化回归检查。

## 验证

- 账号 API 状态 PATCH 与列表回读通过。
- 覆盖安装后验证 WS 页面、手机消息、后台采集和 AI 跟进提醒刷新。
