# 知客 4.4.2 发布说明

## 本轮修复

- 修复从 WS 工作台点击“GPT 运营助手”后标题切换但内容被 WS 页面观察器立即覆盖的问题。
- GPT 导航现在会先声明宿主视图为 `gpt`，避免异步重绘竞争，确保 TeamoRouter/OpenAI 设置入口可达。
- 保留原有 WS 列表级自动采集、AI 分析、跟进提醒、手机/工作台同步和多账号隔离逻辑。

## 验证范围

## 已知限制

- WhatsApp Web 的手机端同步仍取决于 WhatsApp 官方在线状态；本机未产生新消息时无法凭空验证增量同步。
- 仍只处理用户在已登录 WhatsApp Web 中可见或已授权导入的聊天内容，不承诺电脑关闭后的后台采集。
