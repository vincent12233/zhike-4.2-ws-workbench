# 知客 5.1 覆盖升级、备份与回滚

## 升级前

1. 退出知客桌面版和 Docker API/Worker。
2. 复制 `%LOCALAPPDATA%\Zhike` 到一个带日期的离线目录（至少包含 `desktop-connection.json`、`ai-credentials-winui.json`、WS profile 目录和布局 JSON）。不要把副本提交到 Git 或发送给他人。
3. 使用数据中心导出一份完整 JSON/CSV 业务备份，并确认导出文件可读。
4. 记录当前安装目录和安装包 SHA-256。

## 覆盖安装

安装器只替换程序目录中的 WinUI 文件，默认不删除 `%LOCALAPPDATA%\Zhike`。安装失败时不要手动删除该目录；先保存安装日志，再重新运行安装器或选择兼容页面。

## 回滚

1. 卸载 5.1（卸载向导默认保留用户数据）。
2. 安装上一版程序文件，或将备份的程序目录恢复到原位置。
3. 保留并重新使用同一 `%LOCALAPPDATA%\Zhike` 数据目录。
4. 启动后先只读检查客户数、跟票/入金数量、跟进任务和 WS 账号状态，再进行任何写入。
5. 如果发生版本冲突，使用页面提供的恢复副本/快照，不要直接删除数据库表。

## 数据恢复边界

- PostgreSQL 数据恢复使用 Docker/数据中心提供的备份和迁移流程；桌面安装器不执行破坏性数据库恢复。
- AI 凭据文件按版本隔离：WinUI 不覆盖 Electron `ai-credentials.json`，回滚 Electron 时原凭据仍在原位置。
- 永久删除、清空全库和物理删除必须在数据治理/服务器端进行二次确认；本安装器不会自动删除业务数据。
