# 知客 4.4.1 产品级重整测试报告（历史记录）

> 本文记录 4.4.1 的历史验收，不代表当前 4.4.24/v5 交付结果。当前版本请以 `docs/release-notes-v5-server-desktop.md` 和 `docs/v5-implementation-report.md` 为准。

## 4.4.1 WS 列表级采集与同步补充

- 通过 `node scripts/run-tests.cjs all` 完成 38/38 项源码、API、安全、迁移、性能、备份、HTTP 和回归检查。
- 通过 WS 安全契约检查：采集逻辑不读取密码、Cookie、二维码或秘密 Token；列表扫描使用受限 DOM 属性并保留原文。
- 列表级采集使用会话外部标识和预览指纹幂等写入；手机消息同步依赖 WhatsApp Web 已完成页面同步，工作台不调用个人账号后台接口。
- AI 未配置或请求失败时，原文仍先保存，采集项会标记为“待重试”并保留可读错误原因；成功分析会清除该状态并生成去重后的跟进提醒。
- 隔离工作台已由用户配置 TeamoRouter；最小连接请求返回“TeamoRouter 连接成功”，隔离聊天分析返回意向、紧急程度、下一步和跟进日期。

## 4.4.0 清空全库修复

一键清空全库改用知客内置密码弹窗，移除对 Electron 不支持的原生 `prompt()` 依赖；清空前快照、密码校验、失败回滚和空库提示均保留。

## 4.3.2 窗口稳定性补充

WS BrowserView 改为跟随实际容器尺寸伸缩，采集区限制最大高度；侧栏收起、辅助栏切换、窗口缩放和 DPI 布局变化会通过 ResizeObserver 重新同步嵌入窗口。

## 4.3.1 隔离环境补充

桌面端现支持在 Electron 初始化存储前通过 `ZHIKE_USER_DATA_DIR` 切换完整用户配置目录。隔离启动验收显示客户、任务、跟票和入金均为空，不再读取默认用户目录中的 localStorage 或 WS 分区。

## 4.3.1 新增验收范围

- AI 提醒按最新会话分析去重，低置信度和分析失败结果不误报。
- WS 跟进记录与任务中心同步写入、重复确认和失败回滚。
- 快速录入乱序字段、无标签登记日期和 `DD/MM/YYYY` 日期格式。
- 任务搜索防抖、超大任务渲染窗口和 DOM 监听合并。
- 跟票股票代码搜索分类以及多股票、多笔入金原有口径。

隔离合成数据性能实测（Node 24.22.1）：10,000 客户建立搜索索引约 134ms、查询约 11ms；50,000 客户建立索引约 718ms、查询约 30ms。测试只生成临时内存数据，不读取用户业务库。

测试日期：2026-11-06

## 结论

4.4.1 在当前可执行环境内通过了完整源码回归、列表级 WS 自动采集契约、TeamoRouter 真实连接和隔离聊天分析、AI 跟进闭环、业务筛选、任务/看板隔离、性能规模、备份恢复、完整桌面配置隔离、WS 窗口自适应、清空全库修复和安装器 QA。另用已登录的 WhatsApp Web 实测：无需打开会话即可识别 3 个列表会话并完成 `3/3 已采集`，待重试为 0；重复采集不会重复写入，旧标题会原位更新为列表预览原文。真实业务会话仍需按现场登录状态验收，手机端与工作台仍依赖 WhatsApp Web 自身在线同步，电脑关闭后不承诺后台采集。
