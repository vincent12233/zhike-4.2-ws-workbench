## 本次重点修复

- 主窗口与 WS 布局状态分离，修复 DPI 重复缩放和 820×540 操作不可达。
- PostgreSQL 客户模糊搜索索引；同客户同股票的交易按流水号保留独立记录。
- 导入源哈希重复检测，重复文件禁止直接提交；登记日期保持历史值。
- WS 使用页面变化触发采集并保留 30 秒兜底；页面结构不识别时暂停写入并报告错误。
- AI 任务队列支持查看状态及重试失败任务。
- 不支持的页面故障不再静默跳回首页。
- WebView2 缺失时安装器提供微软官方下载入口。
- 配置证书时实际调用 SignTool 签名程序和安装包并执行验证。
