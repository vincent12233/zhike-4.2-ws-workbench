## 安全、证据与回滚

本轮只使用隔离目录、临时 SQLite、合成数据和被阻断外联的原生构建。没有读取正式客户库、Cookie/Token 或真实账号 profile；没有启用正式 Worker/AI、旧新双写或 RD02 隐藏采集。必要日志均去本机路径，截图仅合成资料，证据源和归档 SHA-256 分开记录。归档不包含任何 profile、SQLite、连接令牌文件。

本轮原生临时根 `zhike-stage51-native-7e4e4228cd6240a18628edc0c7cb0fcd` 暂留用于诊断。第二轮 Edge 失败夹具 `zhike-stage51-layout-fAR1qQ` 由失败清理机制保留。没有绕过清理审批或强制递归删除。具体物理路径只存本地诊断会话，正式报告以唯一目录名定位。

稳定基线 `eb94848` 保留；各模块独立提交，回滚使用经审查的逆序 `git revert`，不删除用户资料、不降级数据库、不覆盖已有工作。未合并 KPI 原型保留在独立分支。最终报告提交与工作区状态在本轮交付回复记录；验收失败时不得通过改变版本号或安装包发布规避门禁。

**最终 S3 Gate：BLOCKED。生产：FROZEN。** 下一步先继续在已归属的隔离 Edge 进程记录结果就绪、OS 退出和流关闭各阶段，定位尚未解释的超时；在可稳定捕获的 Windows 桌面补原生矩阵。真实成员/回执适配必须另有授权来源验证。只有 S3 所有必需项满足后，才能继续后续完整业务验收，生产发布仍需独立安装、设备迁移和其他既有门禁。
