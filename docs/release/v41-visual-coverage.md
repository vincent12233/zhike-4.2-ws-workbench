## 对比度检查

CRM、WS 和 GPT 的测试夹具共用 [背景合成计算器](../../tests/helpers/visual-contrast.cjs)。它从祖先到当前元素依次合成背景色，按 CSS 绘制顺序从底层到顶层保留各渐变停点的透明度，再以停点组合的保守最小值检查 4.5:1。WS 普通卡片同时检查一级材质的背景色和渐变层。业务摘要标签复用已有的 `--b6-kpi-ink` 语义前景色。按实际 CSS 令牌进行的 [Node 回归](../../tests/ws-visual-alpha-composition.test.cjs) 覆盖透明高光、叠层反光、父背景与本层不透明底色，以及低对比拒绝案例。所测 KPI 的浅色、深色保守下界分别为 5.303:1、6.070:1。所测一级材质文字下界分别为 5.830:1、4.848:1。数值范围限于测试中的配对。
