Its sole failure was `Delivery S1 actual main renderers and shared design system`. A single serial rerun of the original script used the independent Windows observer and returned exit code 1.

The timestamps in the table are elapsed milliseconds since each launcher started. Both invocations recorded a successful protocol response to `Browser.close` followed by WebSocket close code 1000. At the deadline neither Node process `exit` nor stream closure had been observed. The launcher requested termination via its owned handle and locally destroyed its streams. Both invocations retained `cleanupSafe=false`. The identity probe's EOF and fallback termination occur during that failure handling. Its query results had already been returned on a separate pipe before browser shutdown began.

The original failure has no independent kernel log. The rerun used the original 30-second browser budget, the default cases and the original assertion sequence. Its first five invocations produced [assertion-completion markers](recheck/assertions). The sixth collected the Operations renderer result and screenshot before `process-exit` timed out. The caller's screenshot assertions were never reached for that invocation. The [command record](recheck/command.result.json) covers the whole rerun.

The [kernel trace](recheck/kernel.jsonl) verifies the rerun's Edge root PID `34396` and Windows creation ticks `639306253117599549`. All three samples and the final observation report the same process running, with no exit code. The process handle returned `WAIT_TIMEOUT` (258) at the original deadline. The narrow clock bracket places that terminal sample at 30000.838–30001.312 ms on the launcher's elapsed clock, before the 30001.611 ms fallback termination request. This establishes an actual delay in Edge's OS process exit in the rerun. The process held the same CPU totals at all three samples and at the deadline. Thread observations returned `ArgumentException`, so the evidence does not identify the internal wait or the responsible component.

An earlier run, `1795025504869-33e3d860-f991-4008-baba-424e98b39b51`, passed the same Horizon Night case on the same 20 routes and matched the selected layout geometry. It closed its transport at 3074.800 ms and observed browser exit code 0 at 4956.500 ms. The failure recurred on a different case in the observed rerun. A direct causal link to renderer CSS, the polling identity probe or a particular Edge component remains unestablished.

The [read-only process check](process-identity-check.json) looked up the 32 recorded browser process identities, two identity probe PIDs and one observer PID. All 35 PIDs were absent at check time. Browser identities include creation ticks. The helper records contain PIDs only, and the kernel observer has a separately recorded exit code 0. The check covers the recorded identities at that time. The retained fixture roots were neither opened nor removed.
