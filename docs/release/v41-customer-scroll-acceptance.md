# UI01 客户抽屉滚动回归

2026-11-18 在隔离 Edge 中运行现有客户中心渲染器及增强模块，使用 52 条合成客户记录。基线为 `8b7dfd0`，修复源提交为 `0181804`，主线提交为 `a009247`。以下证据覆盖 CSS 视口中的定向回归。本轮没有 WinUI 原生截图、整套视觉矩阵或 .NET 复测。归档阶段只读取和校验已有证据。

## 复现与修复

默认模式及 `ZHIKE_TABLE_CAPTURE_PALETTE` 模式均复现。抽屉原先在报名历史异步挂载前滚到底，随后 `#v4RegistrationHistory` 加载并令最大滚动位置增加 171 px，固定操作栏遮住末节。1280×900 的定向诊断在同一断言前额外记录了加载状态、两个最大滚动位置和 `scroll-behavior: auto`。另有一项跨午夜的合成日期错误，UTC 生成了 11 月 17 日，产品按本地 11 月 18 日统计。

修复只调整现有测试。测量前等待真实报名历史的 `loaded` 状态，并用产品当天日期生成合成记录。原有几何断言和时间预算继续适用。

## 证据与脱敏

归档收录 8 份断言日志、8 份浏览器结果、8 份生命周期记录及 5 张真实 Edge PNG。截图记录客户表格横向滚动场景。抽屉可达性由几何结果与断言日志记录。逐张目视检查只见合成数据，PNG 结构检查没有文本元数据或附加数据。 [1280×800 浅色截图](evidence/v41-customer-scroll/after-800-capture-atelier-dawn/horizontal.png) · [1280×800 深色截图](evidence/v41-customer-scroll/after-800-capture-horizon-night/horizontal.png) · [1280×900 浅色截图](evidence/v41-customer-scroll/after-900-capture-atelier-dawn/horizontal.png)

5 张 PNG 与 8 份浏览器结果保留原始字节。日志副本将换行转换为 LF，并替换失败堆栈中的本机工作区路径。生命周期副本删除临时 profile 路径，使用归档运行标签替换原始调用 ID，并将附件引用改为归档相对路径。25 处本机绝对路径引用已替换或移除。凭据、完整 Windows 用户 SID 和临时 CDP 地址的模式扫描无命中。清单分别记录源文件与归档文件的 SHA-256，明确标记脱敏副本。共核验 31 个条目，包含 29 份运行证据、索引及扫描记录。 [敏感内容扫描](evidence/v41-customer-scroll/sensitive-scan.json) · [SHA-256 清单](evidence/v41-customer-scroll/manifest-sha256.json)
