# 知客 6.1.0 A+B 预发行说明

预发行标签为 `v6.1.0-rc.1`，程序与安装器版本为 **6.1.0**。从 GitHub 对应预发行条目取得 `zhike-6.1.0-win-x64-setup.exe` 并核对随附清单。清单和本次实际签名状态由交付产物提供。

## 首次启动

Windows x64 内部版本须为 22621 或以上。请先安装 Microsoft Edge WebView2 Evergreen Runtime，再运行知客安装器。缺少运行时时知客安装会中止。安装完成后，从桌面或开始菜单打开“知客工作台”。本机 SQLite 在 `%LOCALAPPDATA%\Zhike6`。首次使用此目录为干净空库，旧 `%LOCALAPPDATA%\Zhike` 数据不会自动读取或迁移。

先进入“客户中心”或“快速录入”，用本机资料验证录入与保存。升级或换机前在“数据中心”导出备份。换机后需要重新登录 WhatsApp 并配置 AI Key。完整步骤见随包《本机部署说明》和《故障排查》。

## 这次候选包含

- 主界面与 WS 工作台统一的视觉组件、头像回退、可读对比与客户 360° 信息入口。
- 客户编辑、VIP 冲突保护、历史跟进日期和并发保存的修正。
- WS 返回导航、账号创建一致性、启动错误提示和同账号重试的修正。
- 随包 Node 检查与本机 sidecar 启动保护。

业务页面和本机数据可离线使用。首次使用普通 WS 前台聊天由用户本人在官方页面扫码或登录。手动导入保留已获准处理的原文。查看已保存的联系人、群组、审计和 AI 建议无需开启后台消费者。显式联网 AI 由用户配置供应商、确认权限和请求范围。

## 已知限制与验收

自动会话发现、自动完整历史、后台采集、后台群监测和认证 profile 复制保持关闭。生产 Worker 和自动 AI 消费者保持关闭。真实 WS 登录与收发、付费 AI、干净 Windows 安装与覆盖卸载、跨设备和完整多 DPI 或物理输入仍待验收。

历史隔离 Edge 退出故障仍保留在验收报告。候选提交的验证记录和资产校验结果以对应 GitHub 预发行条目为准。S3 保持 Blocked，生产自动化入口保持 FROZEN。
