# 知客 6.1.0 A+B 预发行说明

当前预发行目标为 `v6.1.0-rc.4`，程序与安装器版本保持 **6.1.0**。候选发布状态以 GitHub 实际记录为准。[rc.4 候选入口](https://github.com/vincent12233/zhike-4.2-ws-workbench/releases/tag/v6.1.0-rc.4)的安装资产为 `zhike-6.1.0-win-x64-setup.exe`，随附 `release-output-manifest.json`；完整源码提交、文件大小、SHA-256 和实际签名状态以同次清单及实际签名核验为准。已发布的 [rc.3](https://github.com/vincent12233/zhike-4.2-ws-workbench/releases/tag/v6.1.0-rc.3)包含独立采集与生产群组查询，但没有本轮扫码页显示修复；[rc.2](https://github.com/vincent12233/zhike-4.2-ws-workbench/releases/tag/v6.1.0-rc.2)更早。各次候选版本号和文件名相同，请用标签和同次清单区分。

## 首次启动

Windows x64 内部版本须为 22621 或以上。请先安装 Microsoft Edge WebView2 Evergreen Runtime，再运行知客安装器。缺少运行时时知客安装会中止。安装完成后，从桌面或开始菜单打开“知客工作台”。本机 SQLite 在 `%LOCALAPPDATA%\Zhike6`。首次使用此目录为干净空库，旧 `%LOCALAPPDATA%\Zhike` 数据不会自动读取或迁移。

先进入“客户中心”或“快速录入”，用本机资料验证录入与保存。升级或换机前在“数据中心”导出备份。换机后需要重新登录 WhatsApp 并配置 AI Key。完整步骤见随包《本机部署说明》和《故障排查》。

## rc.4 扫码页显示修复

- 首次打开 WS、返回前台聊天或切换到独立采集扫码页时，重新读取当前页面、账号和窗口位置；迟到的旧隐藏请求不再把当前扫码页压到壳页面后面。
- 隐藏时明确关闭原生 WS 层的可见内容与输入，显示时恢复完整不透明度和输入。窗口尺寸没有变化也能恢复显示，扫码页不需要等到登录成功才出现。
- 页面位置同步与登录状态探测设置等待上限，避免失去响应的 WebView 让操作一直等待。

回归覆盖生产页面观察脚本及原生显示方法的隔离执行。Windows 编译和合成安装结果以本次构建记录为准；真实 WhatsApp 扫码、目标机画面合成和双会话体验仍需在用户环境确认。

## 保留的 rc.3 实现

- 独立后台采集会话由用户再次扫码登录，与前台聊天分别保存会话及显示状态。请使用当前所选账号的手机扫码；原前台登录资料不会复制给采集端。
- 采集端就绪后，可发现会话、采集已读历史及监测所选群组，支持暂停、恢复、账号隔离与退出回收。未读跳过、去重、范围限制和断点规则保留；不回退到前台聊天视图采集。
- 生产群组管理读取本机群目录、成员关系、同步记录与审计，展示实际已观察的关系。它不保证完整实时花名册，不伪造邀请、移除成员或发送成功结果。
- 全新空库的登记迁移在一次事务中初始化，失败或中断时完整回滚；已有数据库继续按原逐版本事务升级。历史迁移内容和 checksum 不变。

操作步骤和已执行的隔离回归见[独立采集会话说明](independent-collector-followup.md)。采集完成不会自动发起付费 AI；用户显式分析继续使用已有确认流程。

## 保留的 rc.2 修复

安装目标必须为空目录或当前用户已登记的同一知客安装目录；系统、数据、链接路径和新旧目录相交受到保护。新版文件部署成功后才处理旧 Electron 客户端。首次启动显示本机服务连接和页面读取状态，加载失败保留重试入口。客户编辑、VIP 冲突、并发保存、WS 导航和本机 sidecar 启动保护继续保留。

业务页面和本机数据可离线使用。手动导入保留获准处理的原文。查看已保存的联系人、群组、审计和 AI 建议无需开启自动 AI。显式联网 AI 由用户配置供应商、确认权限和请求范围。

## 已知限制与验收

认证 profile 复制保持禁用。生产 Worker 和自动 AI 消费者保持关闭。真实 WS 登录与收发、独立扫码、双会话同时在线与实际采集、付费 AI、干净 Windows 安装与覆盖卸载、跨设备和完整多 DPI 或物理输入仍待验收。Windows 2025 runner 的安装、覆盖与卸载检查使用外部合成数据哨兵；结果以对应运行记录为准。源码隔离回归、Windows 构建和合成安装检查不能替代真实目标机与用户数据升级验收。

S3 保持 Blocked。历史隔离 Edge 退出故障及 rc.2 安装就绪记录仍保留供追溯，不能作为 rc.4 验收结论。候选提交、资产校验和签名结果须以本次实际构建及对应预发行记录为准。
