# WS 账号指标

普通和专用账号页按当前用途分别显示五类指标，刷新不会新建 WebView、复制 profile 或读取凭据：

| 指标 | 口径 |
| --- | --- |
| 已登记账号 | 当前用途本机账号清单数量。登记 50 个账号不要求同时打开或在线。 |
| 已保存登录会话 | 前台与独立采集分别计数，并显示对应账号数。必须有本机原生成功登录观察，且当前 profile 目录创建时间与观察记录匹配。历史 `status`、`lastSeen`、`lastKnownStatus` 不构成登录证据。目录存在但没有可信观察、目录被替换或元数据不可读时为未知。 |
| 近期检测在线账号 | 当前会话代数、当前前台 WebView 的真实登录检测，观察时间不超过 30 秒。独立采集登录不填充前台在线数；无检测或过期显示未知，二维码优先于残留聊天 DOM。 |
| 已初始化 WebView2 | 会话池中 `CoreWebView2` 已初始化的前台与后台实例总数，分别展示。仅分配控件不计入。 |
| 运行采集会话 | 后台 WebView 已初始化、采集状态 running 且安装启动已确认的数量。暂停、导航、进程失败、释放均不计入。 |

`ws.accounts` 的 list 响应新增 `accountMetrics` 快照，含时间、30 秒窗口及逐账号结果。前台按当前用途和账号编号匹配，不沿用旧用途异步响应。页面明确显示快照时间；刷新只读取列表并检测当前已经存在的前台实例，再读取完成后的快照。

本机账号索引新增可选的前台/采集登录观察元数据；原备份不导出这些设备绑定信息。旧索引无需迁移：缺少观察字段时不会推定已保存登录。清会话时先使观察失效，再执行现有 profile 清理；旧代、旧导航和乱序 probe 不能补写旧登录观察。关闭窗口保留已观察的本机会话，但不再计为在线或已初始化。

`tests/ws-account-metrics-native.test.cjs` 使用真实索引、profile 元数据策略及生产 Probe/Save/Clear 方法，配合本地 WebView stub 验证 50 登记和误报边界；`tests/ws-account-metrics-ui.test.cjs` 覆盖普通/专用计数、两份会话对应一个账号、TTL、未知和过期响应。此证据不代表 50 个真实 WhatsApp 账号同时在线验收。
