## 轻量功能与动效

本轮只补齐两项轻量体验，没有一次性增加全部候选功能：

1. **主题预览**：沿用 `zhike.workspace-shell.v1` 和原模态框；选择仅临时呈现，完成才保存。取消、关闭、模态框被替换和卸载时恢复已保存主题。外部原设置保存仍复用既有失败回滚。
2. **既有密度设置真正生效**：继续使用原 `data-density`，实测舒适/紧凑客户行约 55/47 有效像素，字号均为 16px；未新增密度存储或缩小文字。

保存筛选、客户分组折叠、档案预览收放、WS 导航/CRM 收起和首页局部布局记忆直接复用。未新增全局布局库、宽度拖拽器、重复“专注模式”或第二套快捷入口。

动效选取启动品牌淡入、导航图标/颜色反馈、首页 KPI 轻微悬停和按钮阴影；时长约 150–220ms。拖动仅加强阴影，不缩放指针命中目标。停用相关旧无限渐变/流光；列表行、聊天区、原生 host 及其布局祖先不加入位移动画。原客户抽屉的 `transform:none` 和固定底栏修复保留，没有为展开动画重新引入包含块问题。复用既有 `data-motion=off` 与 `prefers-reduced-motion`，不引入动画框架或轮询。
