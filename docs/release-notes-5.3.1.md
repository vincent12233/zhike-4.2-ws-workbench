# 知客 5.3.1 发布说明

## 修复内容

- 修正 WinUI 宿主桥接响应的 JSON 字段名称。页面等待 `requestId`，此前宿主发出的匿名对象会序列化为 `RequestId`，造成每次桥接请求都等到超时。
- 对 `/api/state` 和 `/api/import/` 的写入请求使用最长 120 秒桥接时限；普通页面请求仍使用 15 秒默认时限。
- 将宿主消息限制从约 1 MB 提升至约 50 MB，桥接 payload 限制提升至约 48 MB；超限会由页面立即报错，不再静默等待超时。
- `postMessage` 同步失败时立即清理等待队列并拒绝请求，避免悬挂的计时器和错误的超时提示。
- 安装程序、应用文件版本、Docker/API 默认版本和 WS Worker 版本统一为 5.3.1。

## 数据与回滚

本次不修改数据库结构或用户数据格式。覆盖安装只替换程序文件，用户数据继续保留在 `%LOCALAPPDATA%\Zhike`。若安装后仍无法导入，可退出应用后安装上一版程序；不要删除用户目录或数据库卷。

当前数据库迁移目标仍为 schema 013；本次没有新增迁移文件。

## 验证边界

发布验收记录应区分桥接回归测试、全套自动化测试、WinUI 构建与安装包检查。未连接真实业务库执行的导入不得记为现场验收；用户可以先在隔离副本中验证大文件导入和超时恢复。

## 已知限制

真实业务库的大批量导入、存储空间不足和用户环境中的 WebView2 表现仍需隔离数据或备份副本验证。未在本次执行的现场行为不代表已通过。
