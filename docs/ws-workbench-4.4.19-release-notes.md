# 知客 4.4.19 AI 分析联动客户库与跟进提醒

## 变更

- 新增 `/api/ws/crm-sync` 本机事务接口，把已保存的 AI 分析同步到知客客户、跟进记录和任务中心。
- 通过 WS 外部标识、电话号码、账号标识和会话标识匹配客户；多候选时停止自动合并并提示人工确认。
- 低置信度分析不自动写入客户联系方式、预算等事实字段；原分析仍保存在 WS 专用数据库中。
- AI 跟进记录使用分析编号作为幂等键，重复同步只更新原记录，不重复创建客户或任务。
- 跟进提醒新增未来 7 天窗口，已完成、忽略和延后状态继续保留。
- 同步前自动快照，成功后刷新知客共享状态，失败不阻塞聊天和原有客户功能。

## 验证

- WS 核心与 AI 同步规则测试通过。
- 隔离 SQLite API 测试验证：自动建档、客户关联、跟进任务、重复同步幂等和状态写入。
