## 本次交付内容

- 同一工作台添加多个个人 WS 账号，账号卡片和顶栏标签切换。
- 添加账号使用工作台内嵌表单，不再调用桌面运行时不支持的 `prompt()`。
- 每个账号使用独立持久化 BrowserView 分区和账号级 WS 数据。
- 左侧会话和右侧辅助栏可独立收起为窄轨道，状态按本机工作台记忆；顶部标题、登录工具区和 WS 页面边界均采用紧凑布局。
- 可见会话列表发现、当前可见聊天自动采集、手动导入、原文/译文保留和批次去重。
- AI 摘要、意向/情绪/语言/需求/预算提取、跟进提醒和回复建议；回复默认只复制不发送。
- 客户匹配按 WS 外部标识、电话号码、账号关联、会话标识依次处理，同一客户可关联多个 WS 账号。
- 账号切换时丢弃过期响应，客户和跟进保存失败时恢复原资料。
- 保留原知客客户中心、跟票、入金、统计、数据中心、设置和 GPT 助手业务逻辑。

## 安装后首次使用

1. 启动知客并点击“WS 工作台”。
2. 在左栏点击“添加账号”，输入本机显示名称。
3. 点击“打开 WS”，在官方 WhatsApp Web 页面自行扫码或登录。
4. 在当前可见列表或聊天中采集/导入文本，按需开启翻译和 AI。
5. 确认客户资料后保存到客户中心；确认跟进日期和结果后保存到任务中心。

工作台不读取或保存 WS 密码、Cookie、二维码和秘密 Token；不会绕过验证码、平台安全验证或自动发送消息。

## 备份、升级和回滚

- 升级前在数据中心创建 JSON 备份；安装器覆盖升级和卸载均保留用户 AppData 数据。
- 自动备份只清理自身 `zhike-auto-*.json` 文件，不删除目录中的其他文件。
- 发生异常时先关闭知客，再用数据中心快照或 JSON 备份恢复；清除登录会话只清理当前账号的站点存储，不删除客户、消息、翻译、分析和跟进记录。

## 仍需用户现场确认

- 真实 WS 扫码登录、多个真实账号同时保持登录和平台页面结构变化。
- 用户屏幕上的 820×540、不同 Windows 缩放比例及真实 GPU 驱动下的截图级视觉验收。
- WhatsApp Web 页面不可见内容、关闭电脑后的后台同步和官方个人授权 API；当前版本按页面可见边界工作。
