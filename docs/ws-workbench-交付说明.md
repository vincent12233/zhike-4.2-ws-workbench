## 安装后首次使用

1. 启动知客并点击“WS 工作台”。
2. 建立本机会话，点击“打开 WS”。
3. 在官方 WS 页面自行扫码或登录，点击“我已登录”。
4. 从当前可见聊天复制文本，粘贴到中栏导入框。
5. 按需开启翻译或 AI；回复只复制到剪贴板，由用户回到 WS 页面确认发送。

真实 WS 登录、平台页面兼容性和逐页人工视觉验收仍需用户在自己的账号和屏幕环境中完成。
