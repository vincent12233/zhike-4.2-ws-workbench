## 必须进行的目标机实机验收

- 用户本人扫码登录个人 WhatsApp。
- 手机端新增消息实时到达知客，前台发送与后台采集不重复落库。
- 已绑定 VIP 群的成员身份可唯一匹配并进入正确客户档案和个人跟进评分，普通群与未匹配成员不串档。
- 不停留在 WS 页面时采集、AI 和提醒继续；关机/休眠后正确暂停并能断点恢复。
- TeamoRouter 当前可用模型、超时/503 回退、密钥不进入日志或备份。
- 完整安装包创建桌面快捷方式，打开版本为 6.0.0，覆盖升级保留真实业务数据。

## 当前未验证

目标机 WhatsApp 登录页与二维码已经显示，但本轮没有使用用户真实账号完成扫码，因此手机实时消息、完整历史采集、多账号真实切换和 VIP 群成员归档仍需真实账号参与；TeamoRouter/OpenAI 密钥按“全新工作区、不保留旧数据”的要求未迁移，外部模型可用性、额度与 503 回退仍需配置有效密钥后验证。以上外部项目不能报告为“已验收通过”。
