# 知客 6.0.0 测试报告

状态：开发与回归进行中。本文只记录已经实际执行并留有结果的检查；未执行项目不会标记为通过。

## 必须通过的自动化范围

- JavaScript/C# 语法与 Release 构建。
- 唯一 WinUI + SQLite 运行入口、版本与安装资源一致性。
- 客户、分类、热聊、群组、VIP、跟票、报名、入金、统计、设置、数据中心、回收站与手机号登记回归。
- 智能导入、日期分离、渠道分类、独立业务记录、保存/快照/恢复。
- WS 登录、会话列表扫描、联系人索引、双方消息、普通群排除、VIP 群成员唯一归属、未读跳过、断点补采、多账号隔离、后台跨页面运行。
- AI 证据与客户唯一匹配、只补空字段、冲突保护、提醒权重、任务去重和刷新。
- 820×540、最大化、100%/125%/150%/200% 缩放、键盘与滚轮路由。
- 10,000/50,000 客户搜索、筛选、保存与页面切换性能。
- 新装、覆盖升级、卸载保留数据、换机恢复与安装包 SHA256。

## 必须进行的目标机实机验收

- 用户本人扫码登录个人 WhatsApp。
- 手机端新增消息实时到达知客，前台发送与后台采集不重复落库。
- 已绑定 VIP 群的成员身份可唯一匹配并进入正确客户档案和个人跟进评分，普通群与未匹配成员不串档。
- 不停留在 WS 页面时采集、AI 和提醒继续；关机/休眠后正确暂停并能断点恢复。
- TeamoRouter 当前可用模型、超时/503 回退、密钥不进入日志或备份。
- 完整安装包创建桌面快捷方式，打开版本为 6.0.0，覆盖升级保留真实业务数据。

## 当前未验证

最终安装包、目标机 WhatsApp 页面结构、手机实时消息和外部 AI 可用性尚未在本轮完成实机验收，因此当前不能报告“6.0.0 已验收通过”。
