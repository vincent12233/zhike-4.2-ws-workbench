# 知客 4.2.0 WS 工作台修复与升级清单

## 已完成

- 增加 WS 工作台入口和三栏布局，保持原有知客页面导航可用。
- 增加隔离 BrowserView，允许用户自行打开官方 WS 页面并自行登录；禁止读取密码、Cookie、二维码和秘密 Token。
- 增加未连接、等待登录、登录中、已连接、会话过期、连接失败、正在重连状态，以及打开、登录、刷新、重连、退出和清除本地会话操作。
- 增加总翻译开关、接收翻译、发送翻译、手动翻译、目标语言、显示原文和服务状态。
- 保留原文并独立保存译文；翻译失败不阻塞聊天，关闭翻译后不调用翻译接口。
- 增加会话摘要、意向、意向评分、情绪、紧急程度、语言、产品兴趣、预算、联系方式、阶段、标签建议、下一步和回复草稿。
- 回复默认只复制，敏感内容要求人工确认，不提供自动发送。
- 复用现有客户中心和任务中心；按 WS 标识、电话、会话标识匹配客户，候选不明确时不自动合并。
- 增加 SQLite v5 WS 独立迁移、接口、消息幂等去重、分析/回复记录和诊断导出。
- 自动备份、JSON 完整备份和恢复覆盖 WS 数据；备份保留策略只处理知客自有文件。
- 更新版本号到 4.2.0、安装脚本、README、配置示例、使用说明和故障排查/回滚说明。
- 补充核心、API、安全、备份、性能、安装和启动回归测试。

## 保持不变

- 现有客户、跟票、入金、报名、统计、数据中心、设置和 GPT 助手业务规则。
- 跟票和入金的重复口径：同一客户的不同票据或不同入金不算重复，完全相同记录才拦截。
- 原有 CRM 数据格式；WS 数据使用独立表，不覆盖原字段。
- 用户数据目录和卸载保留策略。

## 仍需现场验证

- 用户本人扫码或登录 WS 后的真实页面显示。
- 真实账号下的可见聊天复制、翻译和人工确认发送。
- WS 平台页面结构更新后的兼容性。
