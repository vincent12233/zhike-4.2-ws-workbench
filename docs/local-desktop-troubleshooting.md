# 知客 6.1.0 A+B 本机桌面版故障排查

## 页面提示“本机服务暂不可用”

先退出所有知客窗口，再重新启动。当前桌面版没有 `%LOCALAPPDATA%\Zhike6\logs` 持久日志目录；本机服务标准输出和错误输出只进入 WinUI 调试输出。普通排查应记录界面显示的完整错误信息，并确认 `%LOCALAPPDATA%\Zhike6\workspace.sqlite` 所在目录可写、磁盘空间充足。重复启动同一工作目录会被 `.workbench.lock` 保护锁拒绝，关闭旧窗口后再试；不要在进程仍运行时手工删除锁文件，也不要删除 `workspace.sqlite`。

## 页面提示“保存异常”

保存异常表示 SQLite 写入失败，不是普通网络提示。先检查数据目录是否可写、磁盘空间是否足够，再点击顶部状态重新同步。批量删除、导入、渠道修改等操作会在写入前创建快照，失败会恢复原值。

## WS 页面空白或提示页面结构未识别

确认 WebView2 Evergreen Runtime 已安装，再在对应账号点击“重新连接”或“刷新页面”。在官方前台页面由用户本人扫码或登录。若旧账号仍显示在列表却启动失败，先重试同一账号；检查连接和页面错误，再决定是否重新登记账号。

手动导入只使用当前获准处理的可见或选中内容。列表预览、历史记录和审计页显示本机已保存资料。认证 profile 复制保持禁用；后台采集使用单独扫码的采集会话。消息方向未知时保留为未知，VIP 群成员身份无法唯一匹配时不归入个人档案。

## 前台已连接，但后台未采集

当前候选 `v6.1.0-rc.3` 已实现独立采集。先确认安装文件及同次 `release-output-manifest.json` 对应 rc.3；已发布的历史 rc.2 不含该能力。选择需要采集的账号，打开“独立采集登录”，请使用当前所选账号的手机扫码。前台与采集端的登录和运行状态分别显示；前台已连接不代表采集端已登录。扫码页面显示期间自动采集暂停，登录完成后返回聊天，再按状态启动或恢复采集。

若仍显示暂停、未登录或错误，按该账号的采集状态处理；不要复制前台 profile 或删除业务库。采集端就绪后可执行会话发现、已读历史采集及所选群组监测；未读跳过和范围限制仍然生效。独立扫码和双会话真实采集仍待目标 Windows 验收。群组页面展示本机已观察记录，不保证等于 WhatsApp 完整实时花名册。详见[独立采集会话说明](release/independent-collector-followup.md)。

## AI 服务不可用

在 GPT 运营助手的“设置 API Key”重新选择服务并测试连接。连接测试会发送测试文字。服务不可用时仍可查看本机原文和已保存结果，核对服务、网络与请求范围后再手动重试。生产 Worker 和自动 AI 消费者保持关闭。

## 今日工作台没有 AI 雷达

首页应先显示加载状态，然后独立读取本机提醒，不需要先进入 WS 工作台。失败时会显示错误与重试。雷达和任务中心复用同一任务；未产生有效分析、未匹配现有客户或客户无需跟进时，显示空状态而不会创建演示提醒。

本版同时修复纵向 Flex 布局把首页模块压扁和雷达绘制裁剪的问题。存在“AI 客户跟进雷达”标题但内容不可见时，应核对正在运行的安装文件与交付清单，而不是仅修改提醒数量或隐藏错误。

## 覆盖升级或卸载

覆盖升级不会删除 `%LOCALAPPDATA%\Zhike6`。卸载后重新安装同一版本，6 系列数据目录仍会被复用；旧 `%LOCALAPPDATA%\Zhike` 不会被读取、迁移或主动删除。如需换机，请先从当前版本数据中心导出备份，再在新电脑导入。

换机后需要自行重新登录 WhatsApp，并重新配置 AI Key。Windows 加密的本机凭据不能当成可跨电脑直接使用的业务备份。

## 安装器提示缺少 WebView2

先安装 WebView2 Evergreen Runtime，再重新运行知客安装器。缺少此依赖时知客会保留现有安装，静默安装也会失败并记录原因。[微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/)

## Windows 拦截未签名安装包

当前更新候选为 `v6.1.0-rc.3`，发布状态以 [GitHub 候选入口](https://github.com/vincent12233/zhike-4.2-ws-workbench/releases/tag/v6.1.0-rc.3)实际记录为准。下载安装时同时取得 `zhike-6.1.0-win-x64-setup.exe` 和同次 `release-output-manifest.json`，不能用历史 rc.2 清单核验新包。核对安装包 SHA-256 与发布项签名状态。请保留 Windows 安全保护。安装器需要 Windows x64 内部版本 22621 或以上。干净目标机验收仍待完成。
