# 知客 6.0.1 Horizon Atelier 本机桌面版部署

当前正式版本只有一套运行链：WinUI 3 + WebView2 + 随包 Node SQLite 本机服务。安装后不需要 Docker、PostgreSQL、远程 API 或配对码。

## 安装

6.0.1 安装包尚未生成和验收。待发布后运行 `知客-6.0.1-WinUI桌面版.exe`，默认安装到 `%LOCALAPPDATA%\Programs\ZhikeNative`。安装器应创建开始菜单和桌面快捷方式，并在安装结束后启动知客；最终结果以实机验收记录为准。

目标电脑需要 Microsoft Edge WebView2 Evergreen Runtime。安装器检测不到时会提示打开官方安装页。

若最终个人分发安装包未做数字签名，Windows 拦截时先使用交付目录中的 `SHA256SUMS.txt` 核对安装包 SHA256；校验不一致时不要运行。不要关闭或绕过 Windows 安全保护。

## 数据目录

6.0 业务数据只保存在 `%LOCALAPPDATA%\Zhike6`，主数据库为 `workspace.sqlite`；首次启动创建空库，不预置演示数据。系统不会读取或迁移旧 `%LOCALAPPDATA%\Zhike`，也不会主动删除旧目录。自动写入前快照保存在新数据库中；SQLite 运行时可能同时出现 `workspace.sqlite-wal`、`workspace.sqlite-shm`，本机服务运行时还会使用 `.workbench.lock`。卸载程序不会删除 6.0 数据目录；覆盖升级也不会覆盖业务数据。

当前正式版不会创建 `%LOCALAPPDATA%\Zhike6\logs` 持久日志目录。本机服务标准输出和错误输出仅转发到 WinUI 调试输出；排查时以界面错误信息、数据目录状态和交付目录中的独立安装验收记录为准，不要删除 `workspace.sqlite`。

## WS 与 AI

扫码登录 WS 并启用采集后，无需手工逐个打开聊天。前台 WhatsApp 可正常聊天，后台隔离采集器持续同步会话列表、联系人索引、双方实时消息并断点补采已读一对一会话和已绑定 VIP 群历史；切换知客其他页面或最小化应用不会停止。主动关闭 WS、清除登录、退出知客、电脑睡眠或断网会暂停。

一对一会话与系统设置中明确绑定的 VIP 群可进入完整历史采集，普通群不采集、不分析、不提醒；类型不明等待重试，未读会话不自动打开。VIP 群按可信 JID/手机号拆分成员，只有唯一匹配到客户中心现有客户的成员才可进入其档案和个人跟进评分，未匹配成员不新建客户，多候选成员不自动归档。手动导入同样执行身份唯一匹配与多发送人防串档规则。

WS 采集的脱敏生命周期诊断位于 `%LOCALAPPDATA%\Zhike6\diagnostics\ws-collector.jsonl`，大小限制为 256 KB；只记录固定事件、计数和时间，不记录聊天内容或客户号码。

WS 工作台只读取用户本人已打开并授权查看的 WhatsApp Web 可见内容。登录、扫码、验证码和密码由用户自己完成；知客不保存密码、Cookie、二维码或秘密 Token。采集的消息、会话摘要、客户资料补齐和跟进提醒写入同一本机 SQLite 数据库。

AI 服务在“设置 → GPT 本机设置”中配置。关闭 AI 后不会调用 AI 服务；AI 低置信度或涉及付款、退款、验证码、身份、金融、法律、医疗、价格/交付承诺时只给建议，不自动发送。

## 备份与恢复

在“数据中心”执行本机备份或导出。只导入由知客 6.0 创建、且 SHA-256 完整性校验通过的 JSON 备份；恢复会先创建写入前快照，失败时自动回滚本次批量写入。旧版数据目录和旧版备份不会被自动读取或迁移。

## 交付验收

自动化测试报告不能替代安装后的实机验收。最终安装包的版本、哈希、覆盖安装数据保持、快捷方式、WS、手机同步和 AI 结果，只以交付目录中单独生成的安装验收记录为准。
