# 多账号 WS 工作台说明

## 账号和登录

工作台支持在同一页面添加多个个人 WS 账号。每个账号有独立的 BrowserView、持久化分区、会话设置、会话列表、原文消息、翻译、AI 分析和采集任务。用户只需填写本机显示名称，扫码和登录始终由用户在当前 WS 页面完成。

工作台不读取密码、Cookie、二维码或秘密 Token，也不绕过验证码和平台安全验证。`打开 WS`、`重新连接`、`刷新页面`、`退出 WS` 和 `清除登录会话`都只作用于当前账号。清除登录会话不会删除客户库或 WS 业务记录。

## 账号切换和恢复

左栏账号卡片和顶栏紧凑选择器都可以切换账号。切换会隐藏旧账号 BrowserView，但保留其独立登录分区；当前账号的客户、会话、翻译和 AI 状态重新加载。切换期间返回的旧请求会被丢弃，避免把账号 A 的内容写入账号 B。应用重启后恢复上次使用的账号；如果该账号已删除，会回退到默认账号并提示重新添加。

## 采集、导入和 AI

工作台可以采集当前 WS 页面可识别的会话列表摘要，也可以自动处理当前可见聊天、手动粘贴聊天文本或导入历史聊天。批次指纹、外部消息标识和回复幂等键用于避免重复写入。每条消息同时保存原文和译文，翻译失败时保留原文。

AI 只分析当前用户选择的本地会话文本，输出摘要、意向、情绪、语言、需求、产品兴趣、预算、联系方式、标签、客户阶段、下一步和回复建议。低置信度结果会提示人工确认，AI 不会自动发送消息。涉及付款、退款、密码、验证码、身份验证、金融、法律、医疗、价格或交付保证时，复制前会再次要求人工确认。

## 客户库同步

保存客户时按 WS 外部标识、标准化电话号码、已有 WS 账号关联和会话标识依次匹配。电话号码相同的多个 WS 账号会关联到同一客户；存在多个候选时需要人工选择。现有客户字段保持兼容，新账号关联以附加字段保存。客户保存失败会恢复本次修改前的资料，跟进保存失败会恢复原跟进和日期。

## 数据、备份和回滚

JSON 备份包含 CRM 数据和各 WS 账号业务数据，但不包含登录分区、密码、Cookie、二维码、秘密 Token 或 GPT API Key。清除登录会话不会影响备份中的客户、消息、分析和跟进。恢复前创建本机快照，自动备份只清理自身命名的旧文件，不删除目录中的其他文件。升级和卸载保留用户 AppData 数据；回滚时先关闭知客，再用数据中心快照或 JSON 备份恢复。

## 已知限制

个人 WhatsApp 没有可供本机工作台承诺后台永久同步的官方接口时，采集能力受 WhatsApp Web 页面结构、登录状态和可见内容限制。工作台不会承诺电脑关闭后接收消息、读取完全不可见的历史、绕过平台验证或自动发送。页面结构变化时，原知客客户中心和其他业务页面仍可独立使用。
