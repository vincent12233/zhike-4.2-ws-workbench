# 知客 4.4.18 跟票买卖记录分离

## 跟票记录

- 同一客户可以为同一股票分别保存买入和卖出记录；记录方向和交易日期共同参与去重，买入与卖出不会互相拦截。
- 旧版只有“跟票日期”的记录继续兼容：买入记录迁移到 `buyDate`，卖出记录迁移到 `sellDate`，原始 `date` 保留作为兼容字段。
- 跟票列表分别显示买入日期、卖出日期，股票代码和买卖方向筛选继续可用；今日、本周、本月筛选按该记录方向对应的交易日期计算。
- 跟票导入、混合业务导入、快速新增、编辑、批量编辑、GPT 新增跟票和运营日报统一使用同一套买卖日期规则。
- 导出跟票明细增加买入日期和卖出日期列，原有客户关联、统计口径和入金逻辑不变。

## 验证

- 新增买入/卖出日期与同客户多笔记录隔离回归测试。
- 全量源码、WS、导入、性能、备份恢复和 HTTP 静态资源回归测试通过后再构建安装包。
