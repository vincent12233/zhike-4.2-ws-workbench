# 4.4.24 业务逻辑兼容合同

本合同用于新版 WinUI 3 + Docker PostgreSQL 实施期间的新旧版本对账。4.4.24 是行为基准，新版只替换技术实现，不重新定义业务。

## 必须保持一致

- 首页数字、客户名单、筛选、统计和点击后的明细；
- 客户字段、渠道、状态、阶段和日期字段含义；
- 登记日期与下次跟进日期的分离；
- 跟票、入金、VIP、报名、任务和看板的记录边界；
- 同一客户不同股票、买入/卖出、不同日期的分开规则；
- 导入、快速录入、批量操作、删除、恢复和同步的成功/失败语义；
- AI只在已确认范围内补充档案和生成跟进提醒。

## 允许的技术增强

- SQLite迁移到PostgreSQL；
- 增量事务、索引、分页、任务队列和性能优化；
- WinUI 3 原生桌面界面和稳定的窗口布局；
- Docker API、AI Worker、备份和 WS Connector Worker；
- 消息去重、断点恢复、字段证据和可观测性。

## 对账规则

对同一隔离输入，旧版和新版必须分别输出客户ID、业务记录键、首页数字、统计聚合、导入分类和任务数量。任何未批准的差异都阻止正式数据切换，并生成差异报告。
