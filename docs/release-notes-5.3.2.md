# 知客 5.3.2 发布说明

## 修复内容

- 5.3.1 已修复桌面桥接响应字段大小写、普通大状态写入时限及消息大小限制。
- 补齐批量导入前自动快照路径：`/api/snapshot` 和快照恢复操作现在使用最长 5 分钟的有界等待，不再被普通请求的 15 秒超时提前中断。
- 普通状态批量写入仍最多等待 2 分钟，普通交互请求仍为 15 秒；桌面宿主、桥接脚本和 HTTP 客户端的等待上限保持兼容。
- 补充运行时回归，分别验证状态写入、导入写入和导入前快照的超时配置及请求响应匹配。

## 数据与回滚

本次不修改数据库结构或用户数据格式，迁移目标仍为 schema 013。覆盖安装只替换程序文件，用户数据继续保留在 `%LOCALAPPDATA%\Zhike`。如需回滚，退出应用后安装上一版本程序；不要删除用户目录或数据库卷。

## 验证结果

- 项目自动回归：66 项通过；
- 桌面桥接运行时模拟：状态写入、导入请求和预导入快照均收到了可匹配响应，并采用对应超时；
- WinUI Release 构建与 5.3.2 安装包构建完成。

真实业务数据库的大批量导入和慢磁盘场景未在用户数据上执行，需使用隔离副本或备份副本做现场验收。

## 已知限制

如果导入仍失败，应从应用提示或日志区分桥接超时、API 连接失败、快照创建失败、导入行校验失败和数据库写入失败；本版本将这些状态保留为不同错误路径，不应视为已通过真实数据库验收。
