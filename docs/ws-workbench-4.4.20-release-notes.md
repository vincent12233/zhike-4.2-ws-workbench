# 知客 4.4.20 发布记录

## 修复内容

- 修复真实 WS 会话验证发现的客户误合并：同一 WS 登录账号下的不同联系人不再因为共享 `wsAccountId` 而合并到同一客户。
- AI 分析自动同步现在按联系人 WS 标识、电话号码、联系人账号或会话标识匹配；无法唯一确定时保留人工确认，不自动合并。
- 增加 API 回归：两个不同 WS 联系人在相同登录账号下分别创建客户、跟进和任务，重复同步保持幂等。

## 实际验证说明

- 4.4.19 已覆盖安装并在实际登录 WS 会话中验证到上述缺陷，因此没有作为最终交付版本保留。
- 本次现场验证产生的自动测试客户、跟进、任务和活动已按精确 ID 删除，WS 会话原有消息和分析记录保留；清理前创建了本机数据库快照。
- TeamoRouter 当前返回“余额不足”时，新的实时 AI 请求会显示可重试错误并保留原始聊天；已保存的高置信度分析仍可独立同步到客户库和跟进提醒。
