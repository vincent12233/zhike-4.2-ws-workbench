# 知客 6.1 全局视觉系统

## 主题与覆盖范围

沿用 `atelier-dawn` 晨光蓝紫和 `horizon-night` Horizon 夜色。应用通过根元素的 `data-palette` 切换现有 CSS 令牌，导航、SVG、面板与头像随同更新。主工作台、快速录入、任务、阶段、CRM、业务、统计和系统页继续使用当前路由及共享控件。WS 外壳和业务页使用同一组件契约，GPT 面板复用共享材质。独立聊天内容仍由其自身主题控制。

|用途|现有令牌与共享组件|
|---|---|
|正文、说明、表面| `--ds-text`、`--ds-muted`、`--ds-surface`、`--ds-surface-soft` |
|工作区强调| `--module-accent`、`--ds-primary`，WS 使用局部既有主题令牌 |
|语义与标签| `--ds-success`、`--ds-warning`、`--ds-danger`、`--ds-ai` 和对应背景 |
|侧栏与工具栏| `--ds-rail-*`、`--ds-topbar-*` |
|面板| `--ds-radius`、`--ds-material-1`、`--ds-surface-border`、`--ds-surface-shadow` |
|图标| `--ds-icon-size`、`--ds-icon-stroke`、`--ds-disabled-opacity` |
|头像| `--ds-avatar-xs`、`--ds-avatar-table`、`--ds-avatar-list`、`--ds-avatar-detail`、`--ds-avatar-hero` |

## 图标与交互

- 功能图标优先引用 `index.html` 的现有 `#i-*` SVG 符号。基础网格为 24×24，线条圆角，默认描边 1.8，使用 `currentColor`。图标尺寸需要调整时，在父级设置 `--zk-icon-size`。
- 带文字的按钮使用 `aria-hidden="true"` 和 `focusable="false"` 的装饰图标。图标按钮提供操作名称，键盘焦点落在按钮上。图表和业务插图保留自身语义与几何。
- 侧栏默认使用轨道前景色，悬停和当前路由继承原轨道强调色，禁用状态使用轨道说明色。主要按钮与业务状态图标继承各自的前景色。强制颜色模式用系统配色指示当前项与键盘焦点。
- 工作台、客户快捷入口和业务操作通过原动作及路由触发。横向表格、纵向滚轮与页面布局由原工作区控制。

## 面板

常用业务面板与 GPT 供应商卡复用 1px 边框、主题圆角、低阴影与顶部高光。新增面板默认添加 `.zk-surface`，重点区域可叠加 `.zk-surface--accent`。可点击、可选中的区域叠加 `.zk-surface--interactive` 并保留原生按钮或链接语义。悬停、选中、焦点、禁用调整边框、背景、阴影、前景和焦点描边，保持布局几何。高对比样式使用系统画布色与焦点色；系统实际高对比模式仍需原生验收。

局部模块可经 `--zk-surface-accent`、`--zk-surface-material`、`--zk-surface-border`、`--zk-surface-radius` 和 `--zk-surface-shadow` 接入现有配色和材质。兼容旧面板时，先复用已有选择器中的令牌。

## 客户头像

`window.ZhikeAvatar.render({name, size, image, vip, selected})` 返回可嵌入现有模板的呈现内容。尺寸为 `xs` 20px、`table` 32px、`list` 36px、`detail` 48px、`hero` 76px。头像为相邻姓名的装饰，屏幕阅读器读取姓名标签。

- 调用方负责验证账号、联系人和客户身份，再向组件传入获授权、已存在的内嵌个人图像。组件接受静态 PNG、JPEG、WebP 的 Base64 数据，拒绝外链、文件路径、Blob、SVG、动画及超出长度限制的数据。它没有网络请求或应用级头像缓存。
- 头像加载使用浏览器懒加载与异步解码，固定尺寸保留回退。图片解码失败时立即显示同一记录的字素或人物图标。捕获阶段的两个资源事件监听器只处理组件实例。
- 姓名头像取首个以字母或数字开头的完整 Unicode 字素。印地语、泰米尔语、数字和其他文字保留原字形，拉丁 ASCII 小写转为大写。空姓名或无法识别时显示共享人物图标。
- 边框继承模块强调色。VIP 可传 `vip: true`，使用现有 VIP 路由对应的语义色。所选记录可传 `selected: true`，详情大尺寸以较低透明度显示光晕。
- 当前授权审计未找到可信的 WS 头像读取与绑定来源，也未找到 CRM 客户头像字段。真实 WS 头像项为 **Blocked**。成员和客户头像使用姓名或默认图标。

## 客户 360°

客户列表与客户 360° 继续使用现有选中客户与详情动作。身份区使用 76px 头像、姓名、号码和实际状态标签。详情按现有数据展示基础资料、热聊、业务概览、群组、跟进、阅读与 AI 摘要。没有可信阅读回执时显示未知，群关系同步状态与空记录分别表达，缺少摘要时保留空态。页面继续从原有 CRM 与 WS 投影读取，档案、编辑、关注和后续业务动作沿用现有接线。

双主题、窗口宽度、缩放、滚轮和运行性能的实际验证结果见发布验收报告。
