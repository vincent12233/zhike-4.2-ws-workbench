## 已知边界

- 个人 WhatsApp 没有适用于本项目的后台永久同步接口；电脑关闭、WhatsApp Web 断开或页面结构变化时，无法保证后台继续采集。
- 不自动发送 WhatsApp 消息；AI 回复只进入预览/复制流程。
