# WS 工作台故障排查与回滚

## 常见问题

### WS 页面显示连接失败

确认电脑可以访问 `https://web.whatsapp.com/`，点击“重新连接”。如果平台页面结构或安全验证发生变化，知客不会绕过验证；可暂时关闭 WS 工作台，原知客仍可使用。

### 翻译按钮提示未配置服务

进入“GPT 运营助手”设置 OpenAI 或 TeamoRouter API Key，再回到 WS 工作台重试。Key 使用 Windows 安全存储，不写入 SQLite、JSON 备份或日志。

### AI 返回格式无效或置信度低

保留当前原文和已有译文，重新分析或人工填写客户字段。低置信度结果不自动写入关键业务承诺。

### 客户保存失败

检查数据中心的本机存储状态和可写权限。工作台会恢复本次修改前的客户对象；确认客户是否已被其他窗口修改后再重试。

### 重复消息

相同会话的相同外部消息标识只保留一条。手动粘贴按内容生成本机幂等键，重复粘贴不会重复写入。

## 备份和恢复

- 数据中心“创建 JSON 备份”会同时导出 CRM state 和 WS 独立数据。
- 自动备份文件名为 `zhike-auto-*.json`，只清理自身命名且超过保留数量的文件，不删除目录中的其他文件。
- 恢复前会创建当前工作区快照；恢复失败会恢复内存中的 CRM 状态，并尝试恢复 WS 数据。
- 备份不包含 WS 密码、Cookie、二维码、秘密 Token 或 GPT API Key。

## 回滚

1. 关闭知客，保留用户数据目录和当前安装包。
2. 在数据中心用最近的快照或 JSON 备份恢复；不要删除 `%LOCALAPPDATA%\\Programs\\Zhike` 之外的用户数据目录。
3. 如果 4.2.3 的 WS 功能异常，可卸载程序后安装已验证的 4.2.2 或更早版本；安装器不会删除用户 AppData 数据。
4. 用旧版数据中心恢复原有 JSON 备份。4.1.3 会忽略未知的 `ws` 字段，CRM 数据仍保持原口径。

## 已知限制

- 当前没有适合个人账号的 WhatsApp 官方后台同步接口；工作台会识别当前页面可见的会话列表，并按当前可见内容采集或处理用户导入的聊天文本。页面结构和可见范围仍会限制采集能力。
- 不承诺后台永久同步、电脑关闭后接收消息、自动读取全部历史或自动发送。
- 每个 WS 账号使用独立的持久化本机分区，关闭应用后可恢复该账号的登录页面。清除登录会话只清理选中账号的站点存储；源码不会读取或导出平台 Cookie。
- 本机服务仍是 loopback HTTP，只有外部 GPT 请求使用 HTTPS；服务不对外网监听。
