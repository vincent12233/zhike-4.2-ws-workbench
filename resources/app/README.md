## Windows 桌面版

安装或解压后启动 `知客离线工作台.exe`。工作台会在独立 Windows 桌面窗口中打开，不会启动 Chrome、Edge 或其他外部浏览器。首次启动为全新空白工作区；客户数据保存在 Windows 当前用户的标准应用数据目录。

无需安装 Node、数据库、账号或网络。桌面应用内部启动本机数据服务，所有服务仅绑定 `127.0.0.1`；若默认端口被占用，会自动选择附近可用端口。关闭桌面窗口时会正常保存并停止本机服务。请将工作目录放在可写位置，并定期使用数据中心的 JSON 备份。

## 更换电脑

本程序不绑定电脑、Windows 账号、网卡或硬盘序列号，也不需要激活。更换电脑时，在旧电脑的“数据中心”生成完整 JSON 备份，将该备份带到新电脑，然后在新安装的工作台中选择“从备份恢复”即可继续使用。备份包含客户、业务记录、设置和工作台配置，不包含 GPT API Key；API Key 在新电脑重新填写即可。

## 旧版数据迁移

在“数据中心”中主动选择旧版 `.db` / `.sqlite` 文件。程序只在本机暂存所选文件并以只读方式检查，预览有效客户、归档/合并排除数、来源分类、状态、跟票、入金、完整跟进历史、未关联历史和重复号码；合并客户的历史尽量关联到有效客户，归档或孤立历史仍作为独立记录保留。只有点击“确认并迁移”才会替换当前工作区，写入前自动创建本机快照。原文件不会被写入或删除。首次启动不会自动导入任何旧数据。

- 自适应窄窗口布局；导航、顶部操作区和标题会随宽度调整，宽表格在各自区域内横向滚动，不再强制整页保持 1100px 宽。
- 多维分类、组合筛选、可视化表格、按客户中心/分类视图分别保存的列显示设置与筛选视图（可应用、重命名、删除）、分页、客户编辑、跟进历史及独立跟票/入金记录。批量分配助理、修改状态、排期与热聊标记会先显示受影响人数、原值分布和变更名单，仅写入真正变化的记录；执行前自动快照，并可在当前运行期间一键撤销上次批量操作。
- 跟进、业务明细和群组表格的搜索统一显示匹配条数，并在无匹配时给出明确提示；清空搜索后恢复原始计数。
- 顶部全局搜索与 Ctrl+K 使用即时结果面板，联合匹配姓名、号码、群编号、渠道、助理和备注；精确号码优先，最多展示 20 条高相关结果，可直接打开客户详情或进入客户中心继续筛选。
- 各页面导出与当前视图一致：客户/分类导出筛选客户，跟进/热聊导出当前清单，跟票/入金导出对应业务明细，群组导出群组汇总，统计页导出分析报告。
- 客户中心统一承载客户筛选、批量操作和可恢复删除；客户详情展示跟进、跟票、入金时间线。
- 今日工作台和统计分析共用单导/群粉拆分的当日进退群及当前总量统计，分析报告导出同一口径；卡片可直达对应客户名单，名单中直接展示变更前后状态与时间。当日按客户去重并按变更发生时的归属统计，总量按当前归属统计。从本版本起记录每次状态变更；录入时的已有状态仅作为基线，不计入当日变更；从空白状态实际修改到进群/退群状态仍会计入。详情时间线展示变更日期、时间、来源与前后状态，统计区可导出完整变更明细。旧客户没有历史时不会以当前状态补算当日变化。
- “今天、次日、近 7 天”等日期口径统一使用当前电脑的本机日历日期，跨月、跨年和跨午夜会自动刷新，避免因时区换算导致统计、排期与导出错一天。
- 跟票与入金统计来自实际业务明细，不再因客户标签生成虚构业务行；支持日期、状态、助理与来源筛选。
- 数据治理会实时扫描重复/异常号码；导入异常行可逐条修正后重试、确认忽略或撤销忽略，原始行与处理状态保留在审计记录中。
- 渠道分类可在系统设置中新增、重命名和管理，默认包含“单导”和“群粉”；页面分类是可选的第二层，可用于任意渠道，包括群粉。页面按渠道与页面共同匹配历史数据推荐助理；不设置页面时可直接按渠道归类。旧版平台来源不再作为内置值或导出字段。
- 本地号码规范化、重复号码提示与 CSV 导入/导出；CSV 支持中文表头、UTF-8/GB18030/UTF-16 编码、引号内逗号/换行、字段映射预览和完整导入审计导出。导入复核按渠道和可选页面修改，不再要求旧版平台来源。
- 快速录入按渠道、可选页面、助理和群编号设置本批次常用默认值；群粉默认“在群”、单导默认“未进群”。页面会按该渠道及页面的历史分配推荐助理，仍可手动覆盖。粘贴后可在可视化预览中逐行修正号码、姓名、渠道、页面、助理、状态、群编号和登记日期；支持粘贴清理、下一行定位、重复检查和草稿恢复。
- 登记日期默认为当天；只有勾选手动指定后，批次日期才会覆盖默认值，资料中的有效日期及预览中逐行调整的日期优先保留。系统设置中的渠道、页面分类、助理、群编号、客户状态与客户阶段均可新增、重命名、删除并按类别恢复默认；重命名会同步更新客户资料，删除前显示使用数量并确认。旧版仅保存自定义选项的设置会自动兼容升级。
- 全局文字层级已整体上调，表格、导航、按钮、筛选项和辅助说明更易阅读；在窄窗口中内容仍由表格区域滚动，不缩小字体强行挤入。
- 完整 JSON 备份与跨电脑恢复，支持最大 100 MB 备份；恢复前会在本机建立快照并由用户确认。
- 完整备份会记录最近备份时间；客户库有数据但从未备份、或超过 7 天未备份时出现本地提醒。恢复前显示客户、跟票、入金、跟进的“当前 → 备份”数量差异，明确区分可迁移 JSON 备份与仅供本目录回退的自动快照。
- 恢复时校验客户编号、业务记录、保存视图和设置结构；旧备份缺少后续新增字段仍可兼容，已损坏字段会在创建快照和替换数据前拒绝。
- CSV/Excel 批量导入、快速批量录入、旧库迁移及备份恢复前自动创建本机快照；数据中心可查看并恢复最近 20 个快照。
- 单条修正/忽略导入问题前同样创建快照；关闭页面时会尽力补交小型待写入状态，大型数据库仍应通过“立即备份”或正常关闭本地服务保护。
- 自动化页提供快速录入次日跟进、热聊未跟进提醒和助理分配建议的真实开关，状态保存在本机设置并随 JSON 备份迁移；号码规范、重复保护和写入前快照固定运行。
- 热聊管理按最后跟进日期筛出超过 3 天未跟进客户，可直接查看名单并使用现有批量排期。
- 助理建议按来源页面计算，至少 5 条历史样本且首选占比不低于 70% 才显示；逐条或批量确认后才会写入负责人。
- 旧版 3.28.0 SQLite 数据库的人工选择、只读预览与确认迁移。

## 数据与安全边界

桌面版以独立 Windows 应用窗口承载工作台界面；内部使用随包提供的运行组件和本机服务，不打开外部浏览器。本机服务仅绑定 `127.0.0.1`，并使用每次启动随机生成的会话凭据及来源校验保护数据接口。除用户主动使用 GPT 功能外，工作期间不需要网络；GPT 请求只发送到用户选择的 OpenAI 官方 API 或 TeamoRouter。客户数据仅写入 Windows 应用数据目录与用户主动导出的备份文件，API Key 不进入 SQLite、备份、快照或日志。
## 4.2.6 智能导入与快速录入升级

- 快速录入支持直接粘贴带表头的表格，字段顺序不固定时按表头、样本值和内容特征自动映射。
- 支持登记日期在任意列、中文日期、ISO 日期、紧凑日期和 Excel 日期序列。
- 自动识别联系人号码、投顾来源、客户状态、入群时间、购买股票等常见变体。
- 自动跳过标题行、表头和分隔线；提供“智能整理”“智能填充默认值”和 Ctrl/Cmd+Enter 快速写入。
- 文件名、工作表名和单元格内容可共同推断渠道；单导群组不会误归为群粉。
- 批量导入、快速录入、跟票导入保存失败时恢复内存状态，不重复写入。


## 4.4.19 AI 分析联动客户库与跟进提醒

- WS AI 分析成功后，按 WS 会话标识、号码和账号身份自动匹配或创建知客客户，不覆盖已有业务数据。
- 自动写入 AI 摘要、意向、语言、产品兴趣、预算、标签和客户阶段；低置信度结果只保留在 WS 分析记录，等待人工确认。
- 自动生成幂等的跟进记录和任务，重复分析不会重复建档或重复提醒；未来 7 天内的计划跟进也会进入提醒列表。
- 同步前创建本机快照，写入失败保持原状态；同步完成后刷新客户中心和 WS 提醒。
